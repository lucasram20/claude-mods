# claude-mods-statusline

A themed status line for [Claude Code](https://code.claude.com). It shows the model, a color-coded context bar, git status, the song you are playing (YouTube Music, Spotify and more) and a 12-hour clock. It has no dependencies.

Install steps, options and source: [github.com/lucasram20/claude-mods](https://github.com/lucasram20/claude-mods)
